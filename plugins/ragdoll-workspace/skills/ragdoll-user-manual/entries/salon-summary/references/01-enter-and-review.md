> `salon-promotion-summary-dialog.ts`）與 `test/e2e/9-salon/salon-payment-complete.spec.ts`。

> 對話框、確認結帳進入付款頁、付款頁佈局與金額分項、返回（新單路徑）。**未驗證（⚠️ 僅依原始碼）**：

## 適用情境

`/checkout` 已切到「美容」模式、已登入銷售員與會員、已加入服務項目（或包月）並按過「小計」，
要在美容促銷結算對話框按「確認結帳」進入付款頁。促銷結算對話框本身的操作（折扣碼、會員優惠券、
點數禮物卡等）本次手冊列為待補。

## 操作步驟

1. 在美容促銷結算對話框（畫面標題「**美容結帳優惠彙整**」，左「寵物與促銷」、右「優惠與折抵」：會員優惠券
   驗證、會員點數「禮物卡兌換」與折抵金額「套用」、折扣碼「加入」）底部按「確認結帳」
   （`salon-promotion-summary-confirm-btn`）。底部結算列顯示：小計、促銷、折扣碼、會員優惠券、應付金額，
   並排「後付款」與「確認結帳」兩顆按鈕。
   「確認結帳」與「後付款」共用同一把鎖：其中一顆處理中兩顆都停用，避免連點重複建單。
2. 全部守門通過後導向 `/salon-summary`，對話框關閉，促銷重算被鎖定（避免付款期間金額變動）。
3. 付款頁載入完成的判斷：右下「完成結帳」（`salon-checkout-btn`）出現。

### 參考：E2E 走到美容付款頁的操作序列

`test/e2e/9-salon/salon-payment-complete.spec.ts` 與 `salon-edenred-disable.spec.ts` 使用的路徑，
可作為手動操作的對照：登入銷售員 → 模式下拉切到「美容」（**必須在查詢會員之前切**，切換會清空購物車與會員）→
以手機號碼查詢會員並關閉會員重點資訊彈窗 → 按「新增/修改服務」（`open-edit-services-btn`）開啟
「編輯服務」對話框：新增寵物 → 選分類（如「單次洗澡」「住宿」）→ 在料件列輸入售價與數量（住宿另需起始
時間）→「加入」→「完成」→「加入購物車並結束」→「小計」→ 美容促銷結算對話框「確認結帳」→
`/salon-summary`。帶入未付款單的路徑則是：按「帶入未付款銷售」（`open-unpaid-sales-btn`）→ 在清單該單號
那一列按「帶入」→ 自動開啟促銷結算對話框（鎖定匯入單）→「確認結帳」。

## 進入付款頁前的守門（依序，任一項失敗對話框保持開啟、不導頁）

| 順序 | 情境 | 畫面提示（toast） |
|------|------|------------------|
| 1 | 發票欄位有格式錯誤（留空**不**擋） | 顯示該欄位的格式錯誤說明 |
| 2 | 機台是「美容工作臺」模式（無收銀與發票裝置，不可直接完成付款；小計、瀏覽促銷、後付款不受影響） | 顯示對應原因 |
| 3 | 整單結構性檢核失敗（空車、包月與其他項目混單、包月每寵物每門市 90 天 15 組上限、加購備註、住宿與安親起訖時間、售價數量區間、單寵物項目數上限、已使用包月鎖定、使用包月總額必為 0 等） | **每一項錯誤各跳一則**紅色 toast |
| 4 | 帶入的未付款單有已無法還原的促銷（查無對應主檔） | 「有 N 筆促銷已無法驗證，請先移除後再試」（需先在右欄警示區逐筆移除） |
| 5 | 折扣碼／會員優惠券／點數禮物卡／包月混單的即時重驗失敗 | 顯示對應原因 |
| 6 | 帶入未付款單：原單鎖存的點數／優惠券／折扣碼額度已不足 | 顯示對應原因 |
| 7 | 有會員點數折抵但活動設定已失效 | 「會員點數折抵活動設定已失效，請先移除點數折抵後再試」 |
| 7 | 點數折抵即時核銷失敗且離線／網路層失敗 | 「目前無網路連線，含點數折抵的結帳無法完成，請先移除點數折抵或稍後再試」 |
| 7 | 點數折抵即時核銷失敗（如點數不足） | 顯示後端訊息；無訊息時「核銷點數折抵失敗，請稍後再試」 |

點數折抵是在「確認結帳」當下就預扣（即時核銷），並沿用預先產生的服務銷售單編號，所以在付款頁按
「返回」需要把預扣歸還（見下方「返回」）。

## 進入後應核對的畫面內容

1. 子標題為「**美容付款確認**」。**沒有資訊列**（門市、機台、帳務日等不顯示）。
2. 左上「服務項目」逐列列出：服務名稱、「寵物名 × 數量」、小計；購買包月併列（包月沒有寵物顯示名欄位，
   系統反查寵物清單取名，查不到時顯示寵物編號）。
3. 下方金額區：小計 → 促銷 → 折扣碼 → 會員優惠券 → 會員點數 → **應付金額**。各分項有折抵時顯示紅字
   `-$金額`，沒有時顯示 `-`。應付金額取自美容主 store 的總計，最小顯示 $0。
4. 帶入既有未付款單且**沒有**在對話框編輯過任何促銷細項時，金額為**鎖定路徑**：原封不動沿用匯入快照，
   本頁不重算；一旦編輯過任一促銷細項，改與新單相同、由即時狀態四來源計算。
5. 右側只有「發票方式」「發票明細列印」與付款摘要／完成結帳；**沒有「標記外送單」**，離線時也**不會**
   出現離線提示。

## 返回（左上箭頭，`salon-summary-back-btn`）

### 鎖定條件（按鈕停用）

結帳進行中（進度彈窗開啟到按下「返回購物車」之前）、信用卡（指定金額）已刷成功（已實扣）、One 碼付款成功、
任一宜睿票券核銷（或核銷／查詢中）、信用卡（全額）成功。

### 行為

- 按下後先顯示置中載入圈（避免看到被清空的金額瞬間歸零），並重置付款層（付款方式、刷卡機、宜睿、One 碼）。
- **一般路徑**（新開的美容單）：歸還已預扣的會員點數折抵、解鎖促銷重算、導向 `/checkout`；購物車保留，
  可調整後重新送出。
- **帶入既有未付款單（鎖定匯入單）**：代表放棄補款，**整組購物車與金額清空**、歸還點數折抵，導向
  `/checkout` 並自動重新開啟「未付款單」清單讓人重選。

## 空車與重新整理

- 購物車與包月皆空（且不在結帳流程中）：解鎖促銷重算並 `replace` 回 `/checkout`，不會停留。
  在付款頁按重新整理會因此被導回結帳頁。
- 結帳流程進行中（含完成彈窗尚未按「返回購物車」）不會觸發導回，避免與完成後的導頁重複導航。
