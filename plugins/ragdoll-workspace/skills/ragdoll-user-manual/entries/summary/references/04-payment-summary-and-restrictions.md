## 右下角付款摘要清單

位置：右側欄底部、「完成結帳」按鈕上方。**尚未選任何付款方式時整塊不顯示**。

- 標題「付款方式」，下面逐列：✓ 圖示＋名稱＋金額＋（可移除者）✕。
- 「已付合計」：**列數 > 1 才顯示**（只有一列時不重複顯示）。
- 「找零」：現金多收時顯示，粗體大字（`payment-summary-change-amount`）。
- 「溢收（不找零）」：宜睿＋消費券券面合計超過應付的部分。
- 「尚欠」：琥珀色，已收金額小於應付時顯示。
- 各列金額：現金＝客人實付（未扣找零）；信用卡（指定）／信用卡（離線）指定／消費券＝輸入金額；
  「全額型」（信用卡全額、One 碼、PandaGo、外送平台）＝扣除宜睿與各副付款後的剩餘應付。

### 各列是否可移除（✕，`payment-summary-remove-{key}`）

| 列名稱 | key | 可移除 | 原因 |
|--------|-----|--------|------|
| 宜睿票券 | `edenred` | ❌ | 核銷是即時交易，無法撤銷 |
| 信用卡(指定) | `partial-credit` | ❌ | 已實際刷卡，需走退款流程 |
| 信用卡(離線) | `offline-credit` | ✅ | 純記錄，未實扣 |
| 消費券(不找零) | `stimulus-voucher` | ✅ | 純記錄，未實扣 |
| 現金 | `CASH` | ✅ | 純記錄 |
| 信用卡(全額) | `CREDIT` | ❌ | 已實際刷卡 |
| One 碼 | `TAISHIN_ONE` / `taishin-pay` | ❌ | 已實際扣款（尚未付款成功的等待階段同樣沒有 ✕，靠關閉對話框取消） |
| PandaGo | `PANDAGO` | ✅ | 純記錄 |
| Uber Eats／Foodpanda／Foodomo／寵速配 | `UBER_EATS`／`FOOD_PANDA`／`FOODOMO`／`FAST_BUY` | ✅ | 純記錄 |

移除主付款＝清除主付款；移除離線信用卡／消費券＝清空該副付款，可重新輸入。

## 「已付清款項」與其他常見守門提示

所有付款按鈕在動作前都會過同一組守門規則；不通過時以**黃色警告 toast** 顯示，並中止該次動作
（多數情況鍵盤／對話框根本不會開）。規則依序檢查，先命中的先顯示。

| 提示文字 | 觸發情境 |
|----------|----------|
| 此付款別不符當前通路，請重新選擇 | 銷售單通路不在該付款方式的允許通路內（如外送匯入單選了現金以外的一般付款） |
| 已使用信用卡(全額)，請完成結帳 | 信用卡（全額）已成功後再點「信用卡」 |
| 已使用「信用卡(全額)」完成付款，請完成結帳動作 | 信用卡（全額）已成功後點其他任一付款方式（含宜睿、消費券） |
| 已付清款項 | 未付金額已為 0 時再新增付款；含**現金足額後改成另一個非 0 金額** |
| 已使用信用卡支付部分款項，本銷售不可再搭配使用其他信用卡 | 已有信用卡（指定）再點信用卡 |
| One 碼不得搭配其他付款方式 | 已有信用卡（指定／離線）或消費券時選 One 碼 |
| 若使用宜睿票券，餘額僅可透過現金/信用卡結帳 | 已核銷宜睿後選 PandaGo／外送平台（One 碼按鈕此時直接停用） |
| 若使用消費券，餘額僅可透過現金/信用卡結帳 | 已輸入消費券後選 PandaGo／外送平台 |
| 此付款方式不可與信用卡指定金額搭配 | 主付款是 One 碼／PandaGo／外送平台時再刷信用卡（指定金額） |
| 此付款方式不可與信用卡(離線)指定金額搭配 | 主付款是信用卡／One 碼／PandaGo／外送平台時再加信用卡（離線） |
| 已使用信用卡(離線)指定金額，請先移除再重新輸入 | 已有離線信用卡副付款時再加 |
| 已輸入消費券金額，請先移除再重新輸入 | 已有消費券時再加 |
| 消費券不可與宜睿票券搭配使用 | 已核銷宜睿後輸入消費券，或已輸入消費券後開宜睿面板 |
| 此付款方式不可與消費券搭配 | 主付款是 One 碼／PandaGo／外送平台時輸入消費券 |
| 指定金額需大於 0／指定金額不可超過未付金額 | 信用卡（指定）或信用卡（離線）指定金額不合法 |
| 付款金額不足，請輸入至少 $N 元 | 現金小於應收（**仍會記錄**，不是攔截；見 `02-…`） |

## 可以並存與不可並存（速查）

- 可並存：**現金＋信用卡（指定）**、**現金＋信用卡（離線）**、**現金＋消費券**、**現金＋宜睿**。
- 信用卡（真實刷卡）一筆銷售只能刷一次（全額或指定金額擇一）；信用卡（離線）另外限一筆，
  已有離線信用卡後不能再加第二筆（需先移除）。規則沒有明文禁止「離線信用卡＋真實刷卡」並存，
  這種組合是否符合門市對帳預期未經確認。
- 主付款（現金／信用卡全額／One 碼／PandaGo／外送平台）**同時只能一個**，後選的取代先選的
  （已足額或已成功者被「已付清款項」或鎖定規則擋下）。
- 已實扣的付款（信用卡、One 碼、宜睿）**都不能從清單移除**；純記錄的（現金、離線信用卡、消費券、
  PandaGo、外送平台）可移除。
